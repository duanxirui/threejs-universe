# T15 第 0 阶段：改造前视觉与性能基线（2026-10-20）

> 状态：已采集并保存；这是 **改造前（Before）**，T15 布局/抽屉/纯净/全屏功能尚未开发。

### 已确认的重点问题

- 1707×842：银河首页介绍框范围约 575×592px；底部常规面板 241px 高，自由航行时 282px 高。银河星系被正文和底部横向天体按钮分割。
- 1366×768：自由航行底部面板 282px，占屏幕高度约 36.7%。
- 390×844：地球近景资料框 170px，底部控制区 128px，两部分垂直相邻，合计约 **298px（35.3% 屏高）**。手机银河顶部为 79px。
- 360×740：近景资料框 170px，加上 127px 底栏，合计约 **297px（40.1% 屏高）**。
- 844×390 横屏：底栏 127px，占屏幕高度约 **32.6%**；自由航行控制另有悬浮部分。
- 390×844 自由航行：手动展开“航行导航”时，上方弹出约 **374×123px** 的抽屉，连同底栏约 251px 高。
- 此次 20 张默认布局样本中，文档 `scrollWidth` 均未超过视口宽度；只能说明当时未测到全局水平滚动溢出。

## 页面即时性能读数（非正式跑分）

浏览器页面顶部状态栏显示的 FPS 属于**单次截屏附近的即时 UI 读数**，会受场景纹理异步加载、浏览器视口模拟和其他进程影响；不代表稳定帧率、移动设备 GPU 性能或 60/30 FPS 目标已经达成。

| 场景 | 1707×842 | 1366×768 | 390×844 | 360×740 | 844×390 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 银河首页 | 60 FPS | 60 FPS | 60 FPS | 54 FPS | 54 FPS |
| 太阳系概览 | 51 FPS | 60 FPS | 44 FPS | 44 FPS | 44 FPS |
| 地球近景 | 60 FPS | 60 FPS | 60 FPS | 54 FPS | 54 FPS |
| 自由航行 | 60 FPS | 60 FPS | 60 FPS | 60 FPS | 55 FPS |

单独读取自由航行横屏（844×390）的页面诊断标题：**渲染倍率 1 · 均衡 · 31 次绘制**；质量选项为 **auto**，浏览器设备像素比约为 **1.0**。这些是页面向用户显示的状态。

此次只通过浏览器的只读页面接口采样，无法直接取到主页面 `window.getCosmosPerformance()` 的结构化对象；平均/最低 FPS、GPU 显存、纹理字节数与长期运行负载均未实测。正式真机性能基准仍需在后续验收阶段单独开展。
