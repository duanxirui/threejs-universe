# T15 参考图式布局：改造后视觉对照（2026-10-20）

用户提供的 CAR ATELIER 参考图片用于确定**空间布局**：左上品牌、右上少量全局工具、中央完整 3D 主体、左下场景编号、右下三项功能入口。COSMOS ATLAS 保留自己的品牌、银河/天体渲染及交互语义。

本轮实施后的实际布局：左上 COSMOS，右上搜索、纯净观赏、全屏、设置，左下当前场景/天体和编号，右下「天体资料 / 视角与时间 / 天体列表」。天体目录内保留银河、太阳系、自由漫游的场景切换。按需展开的时间/资料/目录均位于右下菜单上方，关闭后 3D 画面不再被长文案、左侧竖导航或整屏底栏遮挡。

## 功能验证与已知边界

- 桌面本地 Chrome：默认银河全景、右下时间控制（日期轴、播放、镜头复位）及场景/天体目录打开正常，三项工作区互斥。初版银河「天体资料」曾误打开操作指南，随后一度使用单独的居中资料窗；**2026-10-21 已统一为原星球右侧/手机底部资料面板**，银河、太阳系、自由漫游改为展示原左侧介绍与天文数据。操作帮助仍在设置内；地球近景继续显示原参数、对比及卫星导航。
- 390×844：品牌和全局控制在顶栏，三项功能横排在底栏；资料、时间、列表抽屉可用，无水平滚动。本轮截图采集时的纯净模式曾隐藏普通标签，**后续已按用户要求修正为保留品牌、场景提示及原有天体/银河标签**；H 快捷键仍可退出且保留天体状态。这批截图属于四角布局基线，不代表标签修正后的纯净截图。

### 纯净模式标签保留修正（2026-10-20）

用户确认纯净模式只需收起部分操作 UI，不应隐藏品牌和天体标签。修正后的独立实景截图：

- [桌面太阳系纯净模式：保留 COSMOS 品牌和行星名称](pure_solar_brand_labels.jpg)
- [390×844 手机太阳系纯净模式：保留品牌和行星名称](pure_solar_mobile_brand_labels.jpg)

浏览器已确认，银河标记文字在纯净前后仍显示，太阳系标签层继续呈现当前可见行星名称；搜索、设置、底部工作栏仍会收起。标签遵循原有显示开关，不会因纯净模式强制开启此前关闭的标签。这两张图片补充验证**纯净模式修正**，不改变本目录原有 10 张布局测量样本。
- 844×390：右下三项入口保持横向，完整时间/镜头工具向上展开；中心仍可看见地球和银河，没有原先占三分之一高度的底部宽面板。
- Fullscreen API：已接入实际浏览器全屏请求、状态同步和失败提示。受控 Chrome 本轮拒绝了进入全屏，已验证**失败回退提示**，尚不能声称在普通浏览器窗口中成功进入全屏。纯净与全屏状态彼此独立。
- 本轮截图为本地 Chrome CSS 视口覆盖结果，不等于 Android/iOS 实机；未运行长时间 FPS、GPU 内存、跨浏览器全屏和辅助技术验收。
