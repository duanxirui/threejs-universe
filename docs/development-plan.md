## 任务更新规则

新需求按最大任务号顺延；每个任务保留固定编号，并仅在此表更新**当前状态、优先级、依赖和待验收内容**。每日实际工作统一追加到 [对应日期日志](README.md#按日开发日志索引)。记录真实 Git SHA 后将其放在日志，不编造提交。文档每次修改都运行 `node scripts/check-docs.mjs`。
