### 全阶段共同约束

1. **数据与表现层分离。** 数据层保存数值、单位和可用的参考来源；球体放大、轨道间距、视觉速度、粒子、云层及伪色在展示层处理。科普 UI 区分「来源数据」「近似」「示意」，避免将演示轨道当作实时星历。
2. **保持静态站点可部署。** 采用 Node 构建预处理、版本化 JSON/二进制分块及按需加载，不依赖浏览器每帧请求外部星历 API。数据快照、生成命令、源版本和许可可重现；离线范围明确，不缓存无限量星历。
3. **按软件质量验收，不设科学审核门槛（2026-10-27）。** 数据、数值无须逐项科研评审或签核；保留结构/单位/换算/界面/性能等自动检查。需要星历数据才可标记为日期驱动位置，未接入的部分继续明确标注「演示」。不得以示意轨道冒充已提供的日期数据。
4. **延续旧任务编号。** T17 来源标注与 T25 科普数值目录沿用原编号；T14 日期入口在 T26 功能可用并测试后恢复，无须科学审核；旧设备验收及后续修复仍用原 TXX。
