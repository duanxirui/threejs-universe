### 2026-10-27 · [新增] T26：NASA/JPL DE441 四天体 UTC 日期星历与独立演示模式

- **需求/原因：** 按 T25 完成后的既定开发顺序实施 T26。此前太阳系的位置通过 `phase + orbitSpeed × elapsedSimulation` 更新，旧 `seekSimulationDays()` 仅代表任意演示历元，不能按用户输入的 UTC 日期还原天体位置。
- **真实数据获取：** 在本地经授权的只读网络请求确认 NASA/JPL Horizons API 返回 DE441 后，新建 `scripts/science/generate-horizons.mjs`，按目标太阳 10、地球 399、月球 301、火星 499，从太阳系质心 0 获取 **2026-01-01 至 2028-01-01 00:00 UTC** 每日位置和速度。坐标系为 `Ecliptic of J2000.0`，单位 `km` / `km/s`，时间输出 UT/UTC。四天体各取得 **731 组**每日矢量，生成年份分块 `public/data/science/v1/2026.json`（约 170 KiB）、`2027.json`（约 171 KiB），及包含源 URL、DE441、参考中心、时标和支持范围的 `manifest.json`。生成器需主动运行 `npm run ephemeris:generate`；不会在浏览器动画帧中向外部 API 请求。
- **计算与数据接口：** 新建 `src/data/science/ephemeris.js`，提供 UTC 字符串解析、静态年度文件加载、清单和数值范围校验、按每日位置与速度进行 Hermite 插值、从太阳系质心转到日心/地心相对位置并映射到 Three.js 坐标。四天体日期范围外返回不可用，不静默外推。首次启用星历模式才从本站读取 `manifest.json` 和两份年度数据；HTTP 错误重试及回退保持旧演示系统可用。
- **场景与 UI：** `src/universe/createSolarSystem.js` 新增日期模式开关，太阳展示位置固定视觉原点，地球与火星取日心向量、月球取地心向量；其他天体保留原程序化演示位置并标注说明。`src/core/UniverseApp.js` 增加 `enableEphemeris/seekEphemerisUtc/disableEphemeris`，处理用户选择日期、聚焦镜头平移、播放/暂停、倍速和最后采样点停止。`src/ui/ephemerisControls.js` 复用 T31 左侧/手机底部时间工作区，增加 UTC 日期输入、应用和返回演示模式，展示 DE441 与 UTC 状态；`src/main.js`、`src/ui/layoutController.js` 和 `src/workspace-v4.css` 完成入口、布局、响应式、错误信息和状态的联动。**日地视觉距离 14.1 单位/AU、地月间距约 1.9 单位/384400 km，球体仍为增强展示半径；真实比例模式留待 T27。**
