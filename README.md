# COSMOS ATLAS · 沉浸式 3D 宇宙图鉴

COSMOS ATLAS 是基于 **Three.js + Vite + JavaScript + GSAP** 的交互式 3D 宇宙科普项目。可以从银河系全景进入太阳系，观察太阳与八大行星的运动，飞近行星和卫星，并查看天体资料、对比参数或自由漫游。

**在线预览：** https://duanxirui.github.io/threejs-universe/

**推荐探索路线：** 宇宙全景 → 点击太阳系标记 → 太阳系 → 选择地球 → 观察云层与夜侧 → 探索月球 → 返回太阳系 → 探索木星、土星 → 从土星资料进入土卫二/土卫六 → 返回宇宙全景。

这是用于视觉展示和天文科普的模拟器。天体尺寸、距离、运动时间与初始相位均经过可视化调整，不作为精确天文预报。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Three.js / WebGL2 | 3D 场景、相机、天体模型、粒子与实例化小行星 |
| GLSL Shader | 动态太阳、日冕、地球云层与大气等视觉效果 |
| OrbitControls / Raycaster | 旋转、缩放、平移和点击选中天体 |
| GSAP | 场景切换和镜头飞行动画 |
| EffectComposer / Bloom | 可配置的后期辉光 |
| Vite + 原生 JavaScript / CSS | 项目构建、数据和响应式界面 |

## 本地启动

**环境要求：** Node.js 20.19+（推荐 Node.js 22）、npm、支持 WebGL2 的现代浏览器。

在项目根目录执行：

```bash
npm ci
npm run dev
```

按终端显示的地址访问，通常是 `http://localhost:5173/`（若端口被占用，以实际输出为准）。首次安装或依赖变动时，可用 `npm install` 更新依赖及锁文件。

构建生产静态文件和本地预览：

```bash
npm run build
npm run preview
```

构建结果生成在 `dist/`，预览服务通常为 `http://localhost:4173/`。所有天体图片放在 `public/textures/`，运行时从本站加载，不依赖第三方贴图服务器。预制 KTX2 已随项目提供，正常启动**不需要重新编码**；如需从原 JPG 重新生成，使用 Node.js 22.15+ 和已安装的 `ffmpeg`、`ffprobe` 运行 `npm run textures:encode`。

## 使用和操作

页面主要有 **宇宙全景 / 太阳系 / 自由漫游** 三种场景。左上是品牌，右上为搜索、纯净、全屏及设置；左下显示当前场景或天体编号，**左侧竖排按钮**可在不打开抽屉时直接放大、缩小和复位。右下入口按场景变化：银河和自由漫游显示「天体资料」「天体列表/航行导航」，太阳系及天体近景额外显示「天体运动」。运动面板只控制公转/自转的演示倍速；自由航行有独立飞行速度档位。**所有「天体资料」都共用右侧资料卡（手机为底部抽屉）**。场景切换位于天体列表顶部，操作指南位于「设置 → 操作帮助」，自动航行期间始终提供停止按钮。

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖动 / 手机单指拖动 | 旋转视角 |
| 鼠标滚轮 / 手机双指捏合 | 拉近、远离天体 |
| 鼠标右键拖动 / 手机双指移动 | 平移视角 |
| 点击左侧镜头工具的 + / − / 复位，或按 R | 立即缩放、重置当前银河、太阳系或所选天体视角；自由漫游复位会返回初始总览并解除目标锁定 |
| 点击天体或在搜索结果中选择 | 太阳系模式下进入天体近景；自由漫游模式下锁定航行目标 |
| 详情卡选择卫星 / 返回母星 | 进入卫星近景 / 回到对应行星 |
| 进入自由漫游后按 W / A / S / D | 前后左右移动 |
| 自由漫游下按 Space / Shift | 上升 / 下降；可从界面调整飞行速度 |
| 自由漫游的航行导航 → 选择目标 → 飞往目标 | 自动朝目标前进，接近时减速，在安全距离停靠并跟随目标公转 |
| 自由漫游中按移动键或点击“停止航行” | 中止自动飞行并交还手动控制；目标仍保持锁定 |
| 自由漫游中点击“解锁”或按 Esc | 解除目标锁定；航行过程中首次按 Esc 先停止自动飞行 |
| 按 `/` | 打开天体搜索 |
| 点击右下「天体资料」 | 统一打开原星球资料样式的侧边卡/手机抽屉：银河、太阳系、自由漫游展示此前左侧文案及对应天文参数；具体星球近景展示原详细资料（不会自动切换镜头） |
| 右上「设置 → 操作帮助」 | 打开键盘、触控、镜头和航行操作指南，不与天体资料混用 |
| 点击右上“眼睛” / 按 H | 进入或退出纯净观赏模式；收起搜索、设置、底部功能栏、展开的面板，以及**左下角场景信息和编号**。保留 COSMOS 品牌、天体名称标签、银河标记及必要的退出/停止航行入口；标签仍受原有显示开关控制 |
| 点击右上“全屏” / 按 F | 请求浏览器真实全屏；Esc 可由浏览器原生退出。浏览器不支持或拒绝时提示，纯净模式仍可用 |
| 按 Esc | 优先关闭弹窗或正在展开的工作区；无覆盖层时按场景执行停止航行、解锁或返回太阳系 |
| 按 Tab / Shift+Tab、Enter / 空格 | 使用键盘切换并操作搜索、天体选择、对比、时间及画质控件；弹窗打开时焦点保持在弹窗内，关闭后返回原入口 |
| 太阳系/天体近景点击右下「天体运动」 | 仅调整行星与卫星的运动暂停及 0～50× 演示倍速；银河全景和自由漫游不显示该入口 |
| 自由漫游打开「航行导航」 | 设置独立的慢速、标准、快速、极速飞行速度，不影响太阳系的运动倍速 |
| 手机资料抽屉把手轻点或上下拖动 | 切换收起、半屏、展开三种状态 |

**其他界面控件：** 太阳系和天体近景可暂停/继续运动，并选用 0×、0.25×、1×、3×、10×、25×、50× 倍速；轨道与天体标签、画质、参数对比位于相应的设置或资料工作区。

**图标与航行选择：** 顶栏、底部操作、镜头工具、资料卡和弹窗使用相同线宽的内置 SVG 图标，无需加载外部图标字体。自由漫游的「锁定目标」「自由航行速度」在同一面板内：桌面端并排、手机端纵向排列；展开后使用项目统一设计的深色列表、分组标题和选中高亮，长天体列表可以滚动。支持点击选择、方向键、Home/End、Enter 和 Esc；底层仍以原有原生 select 的值及 change 事件驱动业务。选择目标后仍需点击「飞往目标」才会自动航行。

**演示时间：** 当前日期定位、日历输入和时间轴已从界面暂时移除，后续根据真实星历需求重新规划。内部模拟时间与任意日期定位接口仍保留，但页面不再显示容易误解为真实天文日期的日历。太阳系及天体近景采用选定演示倍速，自由漫游使用固定的正常天体公转速率并单独控制镜头飞行速度；银河场景暂停不可见的太阳系演示时钟。该模型始终不能用于精确天文预报。

**手机说明：** 保留单指旋转、双指缩放和平移。左侧另有始终可操作的缩放/复位小工具，展开资料抽屉时自动移到其上方；顶部为品牌与全局按钮，底部在不同场景显示 2 或 3 个功能入口。画质/轨道设置及资料按需打开，自动航行时保留独立停止按钮。不同机型的真实触控、刘海安全区和横竖屏性能仍需实机验证。

**界面改造进度：** T15 已按参考截图完成四角布局和场景化控制，纯净模式、H/F/Esc 与 Fullscreen API 在隔离 Chrome 中经过自动化验证；受控扩展浏览器曾拒绝全屏请求，普通 Chrome/Edge 及真机仍待单独验收，详见 [T15 验收记录](docs/baselines/2026-10-21-T15-browser-audit.md)。

**无障碍与图形恢复：** 场景和天体切换提供文字播报，搜索结果数量及对比表的行列含义有辅助技术标签。浏览器 WebGL 图形上下文中断时，会停止渲染循环和镜头过渡，显示恢复提示；浏览器恢复图形设备后尝试继续，失败时可使用“重新加载场景”按钮。实际屏幕阅读器和显卡中断/恢复兼容性仍需设备验证。

**天体参数对比：** 可比较太阳、行星与卫星。对比表按统一物理单位换算已收录的近似数据，轨道距离明确写为“距太阳”或“距具体母星”；当两者参考中心不同时，会单独提示。这些距离是各天体绕其中心的近似平均距离，不是两个被比较天体之间的直线距离。太阳没有绕太阳的轨道距离和公转周期，显示为“不适用”。原有模拟轨道的大小与速度仍是展示缩放。

**光影增强：** 在自动/高画质下，球形行星或卫星经过太阳与其他天体之间时，可在受照天体表面形成近似柔和阴影；大气边缘的日照过渡以及木星云带也增加了低成本 Shader 动画。阴影是否出现取决于展示轨道的相位，不代表真实日食时间、真实天体投影或精确大气物理计算。低画质保留基础受光和大气辉光，同时关闭增强效果。

**性能查看：** 在浏览器开发者工具控制台执行 `window.getCosmosPerformance()`，可查看当前/平均/最低 FPS、实际 DPR、画质档位、绘制次数、纹理对象数量及 `contextLost` 状态。统计按本次页面会话累计；返回的 `gpuMemoryBytes: null` 表示无法从 Three.js 渲染器直接读取真实 GPU 显存大小。桌面约 60 FPS、主流手机约 30 FPS 属于需要在实际设备检验的目标。

## 科普与许可声明

星球尺寸、相对距离和运动速度采用**演示缩放**，画面中的“演示时间”并非 NASA/JPL 历表。部分轨道参数参考真实天文偏心率与倾角，起始相位为演示设置。天体质量采用 NASA/JPL/NSSDCA 公开的近似物理数值，以 kg 展示，与画面缩放无关。地球、月球和火星的法线效果由现有色彩图估算，不代表真实测绘高程。球体投影、大气散射和木星云带运动属于近似视觉模拟，不用于天文事件预报。真实影像、模拟地貌以及程序化视觉效果有明确区分。

第三方贴图和许可说明参阅 [`public/textures/ATTRIBUTION.md`](public/textures/ATTRIBUTION.md)。CC BY 4.0 纹理需要保留创作者署名。
