# COSMOS ATLAS · 沉浸式 3D 宇宙图鉴

COSMOS ATLAS 是基于 **Three.js + Vite + JavaScript + GSAP** 的交互式 3D 宇宙科普项目。可以从银河系全景进入太阳系，观察太阳与八大行星的运动，飞近行星和卫星，并查看天体资料、对比参数或自由漫游。

**在线预览：** https://duanxirui.github.io/threejs-universe/

**推荐探索路线：** 宇宙全景 → 点击太阳系标记 → 太阳系 → 选择地球 → 观察云层与夜侧 → 探索月球 → 返回太阳系 → 探索木星、土星 → 返回宇宙全景。

这是用于视觉展示和天文科普的模拟器。天体尺寸、距离、运动时间与初始相位均经过可视化调整，不作为精确天文预报。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Three.js / WebGL2 | 3D 场景、相机、天体模型、粒子与实例化小行星 |
| GLSL Shader | 动态太阳、日冕、地球云层与大气等视觉效果 |
| OrbitControls / Raycaster | 旋转、缩放、平移和点击选中天体 |
| GSAP | 场景切换和镜头飞行动画 |
| EffectComposer / Bloom | 可配置的后期辉光 |
| Vite + 原生 JavaScript / CSS | 项目构建、数据和响应式界面 |

| 模块 | 当前功能 |

| 太阳系 | 太阳、八大行星、可显示/隐藏的椭圆公转轨道、倾角、天体自转和公转、1750 个实例化小行星 |

| 探索交互 | 银河系/太阳系/行星近景切换、GSAP 镜头飞行、目标跟随、自由漫游与速度调节 |

这里的“已实现”指代码中已有相应功能，实际效果随设备性能而异。

## 本地启动

**环境要求：** Node.js 20.19+（推荐 Node.js 22）、npm、支持 WebGL2 的现代浏览器。

在项目根目录执行：

```bash
npm ci
npm run dev
```

按终端显示的地址访问，通常是 `http://localhost:5173/`（若端口被占用，以实际输出为准）。首次安装或依赖变动时，可用 `npm install` 更新依赖及锁文件。

构建生产静态文件和本地预览：

```bash
npm run build
npm run preview
```

构建结果生成在 `dist/`，预览服务通常为 `http://localhost:4173/`。所有天体图片放在 `public/textures/`，运行时从本站加载，不依赖第三方贴图服务器。

## 使用和操作

页面主要有 **宇宙全景 / 太阳系 / 自由漫游** 三种入口。可在太阳系点击天体或使用搜索定位，聚焦后通过详情卡切换卫星、返回母星，并从导航栏返回其他场景。

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖动 / 手机单指拖动 | 旋转视角 |
| 鼠标滚轮 / 手机双指捏合 | 拉近、远离天体 |
| 鼠标右键拖动 / 手机双指移动 | 平移视角 |
| 点击天体或在搜索结果中选择 | 镜头平滑飞近并跟随天体 |
| 详情卡选择卫星 / 返回母星 | 进入卫星近景 / 回到对应行星 |
| 进入自由漫游后按 W / A / S / D | 前后左右移动 |
| 自由漫游下按 Space / Shift | 上升 / 下降；可从界面调整飞行速度 |
| 按 `/` | 打开天体搜索 |
| 按 Esc | 关闭弹窗；从天体详情返回太阳系 |
| 手机资料抽屉把手轻点或上下拖动 | 切换收起、半屏、展开三种状态 |

**其他界面控件：** 暂停/继续时间、倍速滑块（0×、0.25×、1×、3×、10×、25×、50×）、轨道与天体标签开关、参数对比、缩放按钮，以及自动/低/高画质选择。

**手机说明：** 已实现单指旋转、双指缩放与平移，以及底部资料抽屉手势；不同机型上的手感、安全区和横竖屏布局仍需实机验证。

## 科普与许可声明

星球尺寸、相对距离和运动速度采用**演示缩放**，画面中的“演示时间”并非 NASA/JPL 历表。部分轨道参数参考真实天文偏心率与倾角，起始相位为演示设置。真实影像、模拟地貌以及程序化视觉效果有明确区分。
